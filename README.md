# CrimeInsight AI – AI-Driven Crime Analytics & Visualization Platform

## 📌 Problem Statement

Law enforcement agencies generate large volumes of crime data, making it difficult to quickly identify patterns, trends, and high-risk areas. Manual analysis is time-consuming and may delay decision-making.

This project provides an AI-driven crime analytics platform that enables users to explore crime data through interactive dashboards, charts, filters, and insights.

---

## 🚀 Features

- Crime Analytics Dashboard
- Interactive Charts
- District-wise Analysis
- Crime Type Analysis
- Year-wise Trends
- Dynamic Filtering
- Crime Insights
- REST APIs using FastAPI

## 📊 API Endpoints

| Endpoint | Description |
|----------|-------------|
| `/api/stats` | Dashboard statistics |
| `/api/crimes` | Crime records |
| `/api/insights` | Crime insights |
| `/api/chart-data` | Data for charts |

## ⚙️ Installation

### Clone Repository

```bash
git clone <repository-link>
```

### Install Backend

```bash
pip install -r requirements.txt
```

### Run Backend

```bash
uvicorn app:app --reload
```

Backend URL:

```
http://127.0.0.1:8000
```
